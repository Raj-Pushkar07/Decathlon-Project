Project Name:
Decathlon Sales Dashboard (Microsoft Excel)

Project Overview:
This project is an interactive Microsoft Excel dashboard built using a synthetic
Decathlon retail sales dataset containing 30,000 sales records. The dashboard
helps analyze sales performance, customer behavior, product categories, profit,
discounts, and other business KPIs through interactive visualizations.

The project was created as part of my learning journey in Excel Dashboard
Development.
